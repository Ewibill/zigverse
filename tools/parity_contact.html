WHY THIS PAGE EXISTS

Glyph's container has no GPU, so a compute kernel cannot be executed where it is written. Every physics error found on 2026-08-07 was caught by a NUMERIC MEASUREMENT rather than by reading code. The proof therefore runs here: identical positions and velocities, both implementations, worst divergence per agent.

THE ONE THING THAT COULD BE WRONG

On the CPU a contact pair is resolved ONCE and pushed both ways. A compute thread may only write its own slot, so the kernel computes every pair TWICE — once from each side — and each thread keeps its own half. If that halving, the normal's direction, or the approach-only damping is wrong anywhere, the numbers below diverge. This harness deliberately uses a CLUMP dense enough that most agents have several simultaneous contacts, since a single isolated pair would hide an accumulation error. It tests the SHIPPING values (k 45, damp 4, per-PAIR ceiling 12) — the stone defaults of k 400 fired shards out of the mass ninety times harder than the field's own forces, which is what "popcorn" was.
