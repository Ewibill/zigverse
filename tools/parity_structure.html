WHY THIS PAGE EXISTS

Glyph's container has no GPU — navigator.gpu is absent — so a compute kernel cannot be executed where it is written. Every physics error found on 2026-08-07 (the bend moment's phantom torque, the force-based wave that tore bodies open, the wake's unit mismatch) was caught by a NUMERIC MEASUREMENT rather than by reading the code. Shipping a shader without one would break the engine's own rule. So the proof runs here instead: identical inputs, both implementations, worst divergence reported per agent.

THE ONE THING THAT COULD BE WRONG

The CPU law SCATTERS — it walks each bond once and writes force to the child, the parent and the grandparent. A compute thread may only write its own slot, so the kernel GATHERS: each agent sums the force on itself from bond i (as child), bond i+1 (as parent) and bond i+2 (as grandparent). That is exactly equivalent for a CHAIN. If the rewrite is wrong anywhere, the numbers below diverge.
